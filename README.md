# 📚 ja-learning-api

`ja-learning-api` is a back-end project for learning Japanese, providing APIs to access resources such as kanji, kana, vocabulary, and grammar.

---

## 🛠️ **Technologies Used**

- **.NET 9.0**
- **MongoDB**
- **Dependency Injection**
- **Repository Pattern**
- **CQRS Pattern**
- **ASP.NET Core**
- **Swagger (OpenAPI)** for API documentation
